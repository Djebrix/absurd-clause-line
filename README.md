One absurd clause buried deep in a terms-of-service agreement, written to `/output/entry.txt`.

Entry for the [The Absurd Clause Contest](https://make.fun/bounty/u-donrulezz-the-absurd-clause-contest-035cc0f1) bounty on make.fun.

## Run

```sh
python3 main.py
```

Writes the clause to `/output/entry.txt` (or `$ENTRY_OUTPUT_DIR/entry.txt` when set).
The program is Python 3 stdlib only, deterministic, and reads no input.
